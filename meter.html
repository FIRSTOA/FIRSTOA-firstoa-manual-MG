사용량 카운터 확인

복합기 요금은 실제로 출력한 장수로 정산합니다. 매달 흑백·컬러 매수를 알려주셔야 요금이 정확하게 계산됩니다.

삼성

MX6 시리즈

  1. 홈 화면을 오른쪽으로 넘깁니다.
  2. [보고서] → [구성/상태 페이지] → [사용 페이지]로 들어갑니다.
  3. 프린터 모양(인쇄) 버튼을 눌러 출력한 뒤 사진으로 찍어 보내주세요.

X3220

  1. 숫자 키패드 위의 [카운터] 버튼을 누릅니다.
  2. 화면에서 [인쇄]를 누릅니다.
  3. 나온 출력물을 사진으로 찍어 보내주세요.

X4220 · X7400

  1. 화면에서 [카운터]를 누릅니다.
  2. 화면 오른쪽 위의 인쇄 모양을 누릅니다.
  3. 나온 출력물을 사진으로 찍어 보내주세요.

제록스 · 후지필름

C2270 · C2275 · C2276 · C3375 / C2263 · C2265 / C2271 · C2273 · C3371 · C3373 / C5585 · C6680

  1. 키패드의 [기계 확인] 버튼을 누릅니다.
  2. 나온 화면을 그대로 사진으로 찍어 보내주세요.

C2060 / C3070 · C3570 · C4570 · C5570 · C7070 / Apeos 신형

  1. 화면의 톱니바퀴 모양을 누릅니다.
  2. [사용 매수 확인]을 누릅니다.
  3. 맨 위 시리얼 번호부터 맨 아래 총 매수까지 한 화면에 나오게 사진으로 찍어 보내주세요.

DocuPrint CM305

  1. [기계 확인 / 사양 설정]을 누릅니다.
  2. [리포트] → [프린터 사용량] → OK 를 누릅니다.
  3. 나온 리포트를 사진으로 찍어 보내주세요.

5005

  1. [사양 설정] → [리포트] → [기능 설정 리스트]를 출력합니다.
  2. 나온 출력물을 사진으로 찍어 보내주세요.

신도리코

D320 · D410 · D420 · D450

  1. [홈] 버튼을 눌러 메인 화면으로 나옵니다.
  2. 화면 왼쪽 위의 [카운터]를 누릅니다.
  3. 나온 화면을 사진으로 찍어 보내주세요.

410 · 450 (버튼식)

  1. 기기의 [메뉴] 버튼을 누릅니다.
  2. 화면 위쪽 [카운터] → [목록 인쇄] → [시작]을 누릅니다.
  3. 나온 출력물을 사진으로 찍어 보내주세요.

400

  1. [기기 유틸리티 / 카운터] 버튼을 누릅니다.
  2. 왼쪽 위의 [미터 카운트]를 누릅니다.
  3. 총 카운터 · 흑백 카운터 · 컬러 카운터가 나온 화면을 사진으로 찍어 보내주세요.

교세라

M5521 · M5526 · MA2100

  1. 왼쪽 아래의 [시스템 메뉴 / 카운터] 버튼을 누릅니다.
  2. 화면에서 [리포트] → [리포트 인쇄] → [스테이터스 페이지]를 출력합니다.
  3. 나온 출력물을 사진으로 찍어 보내주세요.

2101

  1. 화면 맨 아래 가운데의 점 세 개(…)를 누릅니다.
  2. 아래 화살표 한 번 → [카운터 확인] → [기본 설정] → [인쇄 페이지 수]로 들어갑니다.
  3. 아래 화살표를 한 번 더 내린 뒤 화면을 사진으로 찍어 보내주세요.

브라더

MFC-L5700

  1. 화면의 공구(도구) 모양을 누릅니다.
  2. [보고서 인쇄] → [프린터 설정]을 누릅니다.
  3. 4장 중 3번째 장을 사진으로 찍어 보내주세요.

L5100

  1. [+] 버튼을 누르고 [Machine Info] → OK 를 누릅니다.
  2. [Print Settings] → OK → [Go](시작) 버튼을 누릅니다.
  3. 4장 중 3번째 장만 사진으로 찍어 보내주세요.

오키

OKI 5473

  1. 화면에서 [장치 설정] → [보고서] → [시스템] → [인쇄 집계 결과]를 눌러 출력합니다.
  2. 나온 출력물을 사진으로 찍어 보내주세요.

리코

전 기종

  1. 홈 화면 오른쪽 가운데의 앱(네모) 아이콘을 누릅니다.
  2. [사용자 도구] → [카운터]로 들어갑니다.
  3. [카운터 목록 인쇄]로 뽑아 사진을 찍거나, 화면에 나온 사용 매수를 그대로 찍어 보내주세요.

HP

OfficeJet · LaserJet (터치 화면)

  1. 메인 화면 위쪽을 아래로 끌어내립니다.
  2. 톱니바퀴 아이콘 → 목록 아래의 [보고서]를 누릅니다.
  3. [상태 보고서]를 찾아 인쇄한 뒤 사진으로 찍어 보내주세요.

렉스마크

MX410

  1. 집 모양 → 스패너 모양 → [보고서]를 누릅니다.
  2. [장치 통계]를 눌러 출력합니다.
  3. 장치 통계 2페이지를 사진으로 찍어 보내주세요.
