# 퍼스트전산 복합기 사용설명서

고객이 복합기 앞에서 휴대폰으로 보는 매뉴얼 사이트입니다.
유튜브에 올린 작업 영상을 기종·작업별로 찾아볼 수 있게 정리한 껍데기입니다.

빌드 도구도, 서버도 필요 없습니다. HTML·CSS·JS 파일 세 개가 전부입니다.

```
index.html            화면 뼈대
assets/style.css      디자인
assets/app.js         화면 전환·검색 (건드릴 일 거의 없음)
data/manuals.js       ← 내용은 전부 여기 있습니다
```

---

## 1. 영상 넣기 (제일 자주 하는 일)

`data/manuals.js` 를 메모장이나 편집기로 열어 해당 기종을 찾습니다.

```js
{
  id: "samsung-x3", brand: "samsung",
  name: "삼성 SL-X3220NR / X3280NR",
  aka: ["MX3", "3220", "3250", "3255", "3280"],
  videos: { toner: "",  waste: "",  jam: "", ... },
                    ↑ 여기에 유튜브 영상 ID 를 붙여넣습니다
}
```

유튜브 주소에서 **ID만** 떼어 넣습니다.

| 유튜브 주소 | 넣을 값 |
|---|---|
| `https://youtu.be/AbCdEfGhIjK` | `"AbCdEfGhIjK"` |
| `https://www.youtube.com/watch?v=AbCdEfGhIjK` | `"AbCdEfGhIjK"` |
| `https://www.youtube.com/shorts/AbCdEfGhIjK` | `"AbCdEfGhIjK"` |

비워두면(`""`) 그 작업은 **"영상 준비 중"** 으로 표시되고, 글로 된 순서는 그대로 보입니다.
사이트가 깨지지 않으니 있는 것부터 채워 넣으면 됩니다.

## 2. 기종 추가하기

`MODELS` 배열에서 비슷한 덩어리 하나를 통째로 복사해 붙여넣고 고칩니다.

- `id` — 겹치면 안 됩니다. 영문·숫자·하이픈만.
- `brand` — `BRANDS` 에 있는 id 중 하나 (`samsung` `sindoh` `xerox` `kyocera` `brother` `hp` `etc`)
- `name` — **고객 화면에 보이는 이름.** 기기 스티커에 적힌 실제 모델명을 씁니다.
- `aka` — **화면에 안 보이는 검색용 별칭.** 사내 코드명(키슈·세이토·마블 등)은 여기에만 넣습니다.
- `videos` — 그 기종에서 안내할 작업만 적으면 됩니다. 없는 작업은 빼면 목록에 안 나옵니다.

## 3. 작업 종류 추가·수정

`TASKS` 배열입니다. `steps`(순서)와 `cautions`(주의사항)는 기종이 달라도 통하는 일반 내용입니다.
특정 기종만 다르면 그 기종에 `notes: { toner: "이 기종은 ..." }` 를 넣어 한 줄 덧붙일 수 있고,
순서 자체가 다르면 `steps: { toner: ["...", "..."] }` 로 통째로 덮어쓸 수 있습니다.

## 4. 회사 정보

`meta` 에 전화번호·운영시간·카카오톡·유튜브 채널 주소를 넣습니다.
**전화번호를 넣어야 화면 아래 전화 버튼이 켜집니다.**

---

## 확인하는 법

```bash
npm run dev          # http://localhost:8080 으로 열립니다
```

`index.html` 을 더블클릭해도 열리지만, 로컬 서버로 봐야 실제와 똑같습니다.

## 화면이 깨지지 않는지 점검

```bash
npm install          # 처음 한 번만 (점검 도구)
npm test             # 전 화면·검색·체크리스트·영상 연결을 자동 점검
```

기종이나 영상을 고친 뒤 이걸 돌리면, 오타로 화면이 깨지는 일을 미리 잡습니다.

## 올리는 법 (Vercel)

```bash
npx vercel --prod
```

정적 파일이라 GitHub Pages·Netlify 어디든 그대로 올라갑니다.

## 주소 규칙

| 주소 | 화면 |
|---|---|
| `/#/` | 첫 화면 |
| `/#/m/samsung-x3` | 기종별 작업 목록 |
| `/#/m/samsung-x3/toner` | 기종 + 작업 (영상 + 순서) |
| `/#/t/toner` | 작업으로 먼저 들어와 기종 고르기 |
| `/#/s/3220` | 검색 결과 |

기종 주소가 고정이라, **기기에 QR 스티커를 붙여두면** 고객이 찍는 즉시 자기 기종 화면으로 들어옵니다.
