# 퍼스트전산 복합기 사용설명서

고객이 복합기 앞에서 휴대폰으로 보는 매뉴얼 사이트입니다.
유튜브에 올린 작업 영상을 기종·작업별로 찾아볼 수 있게 정리한 껍데기입니다.

빌드 도구도, 서버도 필요 없습니다. HTML·CSS·JS 파일 세 개가 전부입니다.

```
index.html              화면 뼈대
assets/style.css        디자인 (색·간격·그림자를 맨 위 토큰에서 관리)
assets/ui.js            아이콘 24종 + 기기 일러스트 4종 (직접 그린 SVG)
assets/app.js           화면 전환·검색·체크리스트 (건드릴 일 거의 없음)
data/manuals.js       ← 내용은 전부 여기 있습니다
data/channel-videos.json  유튜브 채널 영상 기준표 (연결 누락 점검용)
scripts/fetch-channel.mjs 채널에서 새 영상 찾아오기
tests/smoke.mjs           화면이 깨지지 않는지 자동 점검
```

## 화면 구성

| 주소 | 화면 |
|---|---|
| `#/` | 첫 화면 — 두 갈래 입구 · 기종 · 카카오 · 취급 품목 · 패키지 |
| `#/#models` | 기종 전체 |
| `#/fixes` | 자주 생기는 문제 (증상 목록) |
| `#/pattern` | **4색 패턴 출력** — A4 점검 차트, 바로 인쇄 |
| `#/meter` | **사용량 카운터** — 브랜드별 확인 방법 |
| `#/notices` | 이용 안내 — 장마철·겨울철 용지, 방문 원칙 등 |
| `#/m/<기종>` | 기종별 소모품 · 간단 처리 |
| `#/m/<기종>/f/<증상>` | 기종 맥락에서 본 증상 처리 |

### 4색 패턴 출력 (`assets/chart.js`)

**인쇄는 화면 CSS 를 전혀 타지 않습니다.** 숨은 iframe 에 인쇄 전용 문서를 만들어
그것만 인쇄합니다(`FIRSTOA.printChart`). 화면을 `@media print` 로 걷어내는 방식은
선택자 우선순위 때문에 브라우저마다 결과가 달라 **빈 종이가 나왔습니다.** 되돌리지 마세요.

출력물은 5장입니다 — 검정·파랑·빨강·노랑 **전면**(A4를 여백 없이 꽉 채움) + 종합 차트.
전면 출력은 색이 넓게 깔려야 세로줄·가로 띠·반복 자국·농도 얼룩이 드러나기 때문입니다.

### 종합 차트

A4 점검 차트를 **SVG 도형으로** 그립니다. CSS 배경색으로 그리면 브라우저가 인쇄에서
기본적으로 빼버려 흰 종이가 나오기 때문입니다. 인쇄 설정을 건드리지 않아도 색이 나옵니다.

구성: 원색 4칸 → 농도 11단계 × 4색 → 회색 균형(검정 vs 3색 혼합) → 가는 선 →
글자 크기 → 전면 도포 → 확인란. 좌표는 mm 단위(viewBox `0 0 210 297`).

## 구조 (중요)

내용이 **두 층**입니다. 섞지 마세요.

| | 무엇 | 어디에 | 왜 나눴나 |
|---|---|---|---|
| **소모품 교체** | 토너 · 폐토너통 · (브라더만) 드럼 | `TASKS` + 기종별 `videos` | 기종마다 기계가 달라 영상이 따로 있음 |
| **간단 AS 처리** | 줄 · 걸림 · 센서 에러 등 | `FIXES` (적용 범위 `scope`) | 브랜드가 같으면 방법이 같아 한 번만 쓰면 됨 |

`FIXES` 의 `scope` 로 어디에 나타날지 정합니다.

```js
scope: { all: true }                 // 모든 기종
scope: { brand: "samsung" }          // 삼성 전 기종 (6종에 한 번에 반영)
scope: { models: ["xerox-c2263"] }   // 지정 기종만 — 제록스 시스템 설정처럼 갈릴 때
```

`steps` 가 비어 있으면 화면에 **"내용 준비 중"** 으로 뜹니다.
확인 안 된 절차를 지어내지 않으려고 일부러 비워 둔 것이니, 확인되면 채워 넣으세요.

**드럼은 브라더 5700에만 있습니다.** 다른 기종에 드럼을 노출하면 고객이 요구하게 되므로 넣지 않았습니다.

## 0. 새 영상이 올라왔을 때

```bash
node scripts/fetch-channel.mjs          # 아직 연결 안 된 영상을 알려줍니다
node scripts/fetch-channel.mjs --save   # 채널 기준표까지 갱신
```

유튜브 채널을 훑어서 **사이트에 아직 안 걸린 영상**을 짚어 줍니다.
그 영상 ID를 아래 방법으로 해당 기종에 넣으면 끝입니다.

## 1. 영상 넣기 (제일 자주 하는 일)

`data/manuals.js` 를 메모장이나 편집기로 열어 해당 기종을 찾습니다.

```js
{
  id: "samsung-x3", brand: "samsung",
  name: "삼성 SL-X3220NR / X3280NR",
  aka: ["MX3", "3220", "3250", "3255", "3280"],
  videos: { toner: "",  waste: "",  jam: "", ... },
                    ↑ 여기에 유튜브 영상 ID 를 붙여넣습니다
}
```

유튜브 주소에서 **ID만** 떼어 넣습니다.

| 유튜브 주소 | 넣을 값 |
|---|---|
| `https://youtu.be/AbCdEfGhIjK` | `"AbCdEfGhIjK"` |
| `https://www.youtube.com/watch?v=AbCdEfGhIjK` | `"AbCdEfGhIjK"` |
| `https://www.youtube.com/shorts/AbCdEfGhIjK` | `"AbCdEfGhIjK"` |

비워두면(`""`) 그 작업은 **"영상 준비 중"** 으로 표시되고, 글로 된 순서는 그대로 보입니다.
사이트가 깨지지 않으니 있는 것부터 채워 넣으면 됩니다.

## 2. 기종 추가하기

`MODELS` 배열에서 비슷한 덩어리 하나를 통째로 복사해 붙여넣고 고칩니다.

- `id` — 겹치면 안 됩니다. 영문·숫자·하이픈만.
- `brand` — `BRANDS` 에 있는 id 중 하나 (`samsung` `sindoh` `xerox` `kyocera` `brother` `hp` `etc`)
- `name` — **고객 화면에 크게 보이는 이름.** 기기에 붙은 번호 그대로 (예: `삼성 3220`).
- `full` — 그 아래 작게 보이는 정확한 모델 계열 (예: `SL-X3220 계열 컬러 복합기`).
- `aka` — **화면에 안 보이는 검색용 별칭.** 사내 코드명(키슈·세이토·마블 등)은 여기에만 넣습니다.
- `videos` — 그 기종에서 안내할 작업만 적으면 됩니다. 없는 작업은 빼면 목록에 안 나옵니다.

## 3. 작업 종류 추가·수정

`TASKS` 배열입니다. `steps`(순서)와 `cautions`(주의사항)는 기종이 달라도 통하는 일반 내용입니다.
특정 기종만 다르면 그 기종에 `notes: { toner: "이 기종은 ..." }` 를 넣어 한 줄 덧붙일 수 있고,
순서 자체가 다르면 `steps: { toner: ["...", "..."] }` 로 통째로 덮어쓸 수 있습니다.

## 4. 회사 정보

`meta` 에 전화번호·운영시간·카카오톡·유튜브 채널 주소를 넣습니다.
**전화번호를 넣어야 화면 아래 전화 버튼이 켜집니다.**

## 화면이 깨지지 않는지 점검

```bash
npm install          # 처음 한 번만 (점검 도구)
npm test             # 전 화면·검색·체크리스트·영상 연결을 자동 점검
```

기종이나 영상을 고친 뒤 이걸 돌리면, 오타로 화면이 깨지는 일을 미리 잡습니다.

## 공개 주소

**https://manual.firstoa.co.kr**

GitHub 저장소에 push 하면 Vercel 이 자동으로 반영합니다. 따로 배포 명령이 필요 없습니다.

```bash
git add -A
git commit -m "영상 추가"
git push          # 1~2분 뒤 사이트에 반영
```

### 처음 한 번만 하는 설정

1. **Vercel** 에서 이 저장소를 Import — 빌드 설정은 건드릴 것이 없습니다(정적 파일).
   Framework Preset `Other`, Build Command 비움, Output Directory 비움.
2. Vercel 프로젝트 → **Settings → Domains** 에 `manual.firstoa.co.kr` 추가
3. 도메인 DNS 에 Vercel 이 알려주는 **CNAME** 한 줄 추가
4. 주소가 바뀌면 `node scripts/set-domain.mjs https://새주소` 를 한 번 실행
   (카카오톡 링크 미리보기에 쓰는 절대 주소가 박힙니다)

### 고칠 때 주의

`index.html` 과 `data/manuals.js` 는 캐시하지 않도록 해두었습니다(고치면 바로 반영).
이미지는 일주일 캐시되므로, **같은 파일명으로 사진을 바꾸면 바로 안 보일 수 있습니다.**
파일명을 바꾸거나 Vercel 에서 캐시를 비우세요.
